# Landing de Mostrador

Sitio de venta de Mostrador (nombre provisorio): punto de venta e inventario para negocios chilenos,
desde el PC o el celular que ya tienes.

Sitio estático hecho con [Astro](https://astro.build). Sin cookies, sin analítica y sin formularios.

```bash
npm ci
npm run dev        # servidor de desarrollo
npm run verificar  # privacidad, tipos, compilación, axe y Lighthouse (lo mismo que la CI)
```

- Marca (nombre, logo y colores): `src/marca/`
- Precios: `src/config/precios.ts`
- Textos: `src/textos/`
